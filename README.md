# clx_auto — 一梦江湖挂机助手

这个程序能帮你**自动开号挂机**：它会自己打开游戏、登录账号、选好角色进游戏、在荼蘼里挂上你预设的脚本，然后一直盯着运行情况。你配了几个角色它就依次跑几个，跑挂了会自动重来，全程不用你守着。

> **不会写代码也能用。** 跟着下面的步骤一步步做就行，所有操作都可以通过双击 **`启动菜单.bat`** 完成，不需要敲命令。

# ⚠️ 从别人那里拿到这个项目？先看这里

**别人配好的 `res/` 图片和 `config.yaml` 坐标，在你的电脑上大概率不能直接用。**

程序是靠"在屏幕上找一张小图"来认按钮的，而这种找图是**按像素一比一比对的，不会自动缩放**。只要按钮在你屏幕上渲染出来的大小和原来那台电脑不一样，就会找不到。

> 实测例子：同一个荼蘼刷新按钮，在一台机器上截出来是 132×96 像素，在实际界面里只有 68×68，程序完全匹配不上（把模板从 0.3 倍缩放试到 1.5 倍，最高相似度也只有 0.39）。

**影响渲染大小的因素**（任何一个不同，图片就得重截）：

- 屏幕分辨率
- Windows 的**显示缩放比例**（100% / 125% / 150% / 200%）
- 游戏内的画质 / 界面缩放设置
- 荼蘼窗口的大小

### 拿到项目后要重做哪些、可以直接用哪些

| | 内容 | 说明 |
| --- | --- | --- |
| ❌ 必须重做 | `res/` 里的所有图片 | 全部要在你自己的屏幕上重新截 |
| ❌ 必须重做 | `config.yaml` 里的 `points` 坐标 | 绝对屏幕坐标，见[第五步](#第五步标定屏幕位置) |
| ❌ 必须重做 | `monitor_settings.row` 标定 | 见[第六步](#第六步检查荼蘼面板标定) |
| ❌ 必须重做 | 三个软件路径 | 见[第四步](#第四步填写你电脑上的软件位置) |
| ❌ 必须重做 | `config.yaml` 里的 `regions` 搜索范围 | 绝对屏幕坐标，见[第五步](#第五步标定屏幕位置) |
| ✅ 可以直接用 | 所有代码 | 不用动 |
| ✅ 可以直接用 | 并发数、超时、轮询间隔等参数 | `queue_settings` / `monitor_settings` / `storage_settings` |
| ✅ 可以直接用 | 角色列表的"骨架" | 角色名、是否渠道服、是否启用可以保留，但**每个角色的三张图片都要重截** |

**最省事的做法**：留着 `config.yaml` 里的角色名单，然后用[角色管理助手](#添加或修改角色)对每个角色依次执行「修改 → 重新截取账号图片 / 角色图片」，比从头加一遍快很多。

> 如果你和对方的分辨率、缩放比例、游戏画质设置**完全一致**，那图片确实可以直接用。可以先直接跑[第六步](#第六步检查荼蘼面板标定)的标定检查试试，通过了说明大概率能用。

# 第一次使用

## 第一步：先确认你的电脑符合要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows（Win10 / Win11 都可以） |
| 需要装好的软件 | 一梦江湖客户端、荼蘼脚本软件 |
| 额外软件 | 只有用**渠道服账号**（比如从应用宝、小米商店下载的游戏）才需要装 idv-login |
| 显示器 | 一个显示器就行；**弄好之后不要改分辨率和缩放比例**，改了要重新弄一遍 |

**这个程序运行的时候有几个硬性要求，请务必记住：**

- 🚫 **运行期间不要碰鼠标和键盘**。程序是靠模拟鼠标点击来操作的，你一动就乱了。
- 🚫 **不要让屏幕息屏或锁屏**。程序靠"看"屏幕来判断该点哪里，黑屏了就什么都看不见了。
- 🚫 **荼蘼只能开一个**，不要开多个。

> 建议在一台不用的电脑上跑，或者晚上睡觉前开着跑。

---

## 第二步：安装 Python

Python 是运行这个程序需要的基础环境，装一次就行。

1. 打开 https://www.python.org/downloads/ ，下载 **Python 3.11**。
2. 双击下载好的安装包。
3. ⚠️ **重要**：安装界面最下面有个勾选框 **"Add Python to PATH"（把 Python 添加到环境变量）**，**一定要勾上**，然后再点 Install。
   
   如果没勾就装完了，把 Python 卸载重装一次，记得勾上。

装完之后怎么确认成功了？按 `Win + R`，输入 `cmd` 回车，在弹出的黑窗口里输入：

```
python --version
```

按回车，如果显示 `Python 3.11.x` 就说明装好了。如果提示"不是内部或外部命令"，说明上面那个勾没勾上，需要重装。

---

## 第三步：安装程序需要的组件

1. 打开项目文件夹（就是有 `README.md`、`config.yaml` 这些文件的那个文件夹）。
2. 在文件夹**上方的地址栏**里，把路径删掉，输入 `cmd`，按回车。会弹出一个黑窗口，而且已经定位到了这个文件夹。
3. 在黑窗口里输入下面这行，按回车：

```
pip install -r requirements.txt
```

等它跑完（会刷一堆字，可能要一两分钟）。最后没有红色的 `ERROR` 就是成功了。

---

## 第四步：填写你电脑上的软件位置

程序需要知道游戏和荼蘼装在你电脑的哪里。

1. 用**记事本**打开项目文件夹里的 **`config.yaml`**（右键 → 打开方式 → 记事本）。
2. 找到下面这几行（大概在文件中间位置）：

```yaml
  software_path: "C:\\Users\\74484\\Downloads\\wyclx\\wyclx\\Launcher.exe"
  script_path: "C:\\Users\\74484\\Downloads\\荼蘼.exe"
  idv_login_path: "C:\\ProgramData\\idv-login\\点我启动工具.bat"
```

3. 把引号里的路径改成**你自己电脑上的**：
   - `software_path` → 一梦江湖启动器 `Launcher.exe` 的位置
   - `script_path` → 荼蘼主程序 `荼蘼.exe` 的位置
   - `idv_login_path` → idv-login 的启动文件位置（不用渠道服账号的话不用管）

**怎么获取一个文件的完整路径？** 找到那个文件 → 按住 `Shift` 的同时右键点它 → 选"复制文件地址"，然后粘贴进来。

4. ⚠️ **注意**：粘贴进来的路径里的**单斜杠 `\` 要全部改成双斜杠 `\\`**。

   比如复制出来是 `C:\Games\wyclx\Launcher.exe`，要写成：
   ```yaml
   software_path: "C:\\Games\\wyclx\\Launcher.exe"
   ```

5. 改完保存（`Ctrl + S`）。

---

## 第五步：标定屏幕位置

程序靠"点击屏幕上的固定位置"来操作，所以要告诉它每个按钮在你屏幕的哪个坐标。**换了电脑、换了分辨率或缩放比例，都必须重做这一步。**

好消息是：全部 7 项都填在 `config.yaml` 里，**不用改代码**。

### 5.1 先学会怎么量坐标

1. 打开游戏走到登录界面，同时把荼蘼也打开。
2. 双击项目文件夹里的 **`helper.py`**（双击打不开的话，在[第三步](#第三步安装程序需要的组件)那个黑窗口里输入 `python helper.py` 回车）。

   屏幕上会出现一个跟着鼠标跑的小方块，实时显示当前鼠标的坐标 `(x, y)`。
3. 把鼠标移到目标位置，读出小方块上的两个数字记下来。按 `Ctrl + C` 或关掉窗口即可退出。

**要量"一个点"**（比如某个按钮）：把鼠标放到那个按钮**中间**，读一组 `x, y`。

**要量"一块矩形范围"**：读两次——先把鼠标移到范围的**左上角**读一组，再移到**右下角**读一组，然后换算：

```
左 left   = 左上角的 x
上 top    = 左上角的 y
宽 width  = 右下角的 x － 左上角的 x
高 height = 右下角的 y － 左上角的 y
```

> ⚠️ 配置里填的是 `左/上/宽/高`，**不是四个角的坐标**。别直接把右下角的坐标填进去。
>
> 💡 矩形范围是用来"在这块区域里找图"的，**宁可框大一点**，只要能完整盖住展开后的列表就行。

### 5.2 要量哪 7 个

**打开游戏登录界面时量这些：**

| 编号 | 量什么 | 类型 |
| --- | --- | --- |
| ① | **角色选择**下拉框 | 点 |
| ② | 角色列表**中间**任意一点（滚轮翻页时鼠标停这儿） | 点 |
| ③ | 能框住**展开后的账号下拉列表**的范围 | 矩形 |

**打开荼蘼时量这些：**

| 编号 | 量什么 | 类型 |
| --- | --- | --- |
| ④ | 左侧导航栏最上面的 **"日常"** 菜单 | 点 |
| ⑤ | **第 1 行**的"方案选择"框 | 点 |
| ⑥ | **第 1 行**的"开始"按钮 | 点 |
| ⑦ | 能框住**展开后的方案下拉列表**的范围 | 矩形（只要左/宽/高） |

> - ⑤⑥ 只要量**第 1 行**，其他行程序会按行高自己算。
> - ⑦ 不用量"上边界"，程序会按角色所在的行号自己算。
> - 荼蘼的**刷新按钮不用量**，程序靠认图标找它。

量完照着这张表把数字记全，再一次性填进去：

```
① 角色选择下拉框    x = ____  y = ____
② 角色列表中间      x = ____  y = ____
③ 账号列表范围      左 = ____ 上 = ____ 宽 = ____ 高 = ____
④ 日常菜单          x = ____  y = ____
⑤ 方案选择框        x = ____  y = ____
⑥ 开始按钮          x = ____  y = ____
⑦ 方案列表范围      左 = ____           宽 = ____ 高 = ____
```

### 5.3 填进 config.yaml

用**记事本**打开 `config.yaml`，找到 `points:` 和 `regions:` 这两段，把数字换成你量到的：

```yaml
  points:
    select_role:              # ① 角色选择下拉框
      x: 1930
      y: 1250
    tu_mi_daily_menu:         # ④ 荼蘼左侧导航栏的"日常"菜单
      x: 123
      y: 87
    script_choose_base:       # ⑤ 荼蘼第1行的"方案选择"框
      x: 952
      y: 116
    script_run_base:          # ⑥ 荼蘼第1行的"开始"按钮
      x: 1178
      y: 119
    script_dropdown_offset_y: 30   # 方案列表展开后第一个选项的纵向偏移，一般不用改

  regions:
    account_list:             # ③ 账号下拉列表的搜索范围
      left: 2100
      top: 980
      width: 2220
      height: 1100
    script_list:              # ⑦ 方案下拉列表的搜索范围（不用填 top）
      left: 0
      width: 1500
      height: 1200
```

再往下找到 `role_list_scroll:`，填 ②：

```yaml
  role_list_scroll:
    point:                    # ② 角色列表中间任意一点
      x: 1930
      y: 1250
```

改完保存（`Ctrl + S`）。

> 💡 保存后可以直接跑[第六步](#第六步检查荼蘼面板标定)的检查工具，它会顺带验证 `config.yaml` 有没有写坏（缩进错了会报错）。

## 第六步：检查荼蘼面板标定

程序要能"看懂"荼蘼面板上每一行是什么状态（绿色=在跑，粉红色=游戏崩了，白色=空闲）。这一步用工具自动检查，很简单。

1. **先把荼蘼打开**，让它显示在屏幕上。
2. 双击 **`启动菜单.bat`**，输入 `1` 回车。

程序会自动截图、逐行检查，然后：

- 在黑窗口里列出每一行读到的颜色，每行前面有个 `√` 或 `?`
- 生成一张 **`标定检查图.png`** 并自动打开

**怎么看这张图：**

| 图上的标记 | 应该在哪 |
| --- | --- |
| 🔴 红色圆圈 | 落在每行左边的**状态色块**上 |
| 🟩 绿色方框 | 正好框住**任务状态那一列的文字** |
| 🟠 橙色横线 | 和界面上每行的**分隔线对齐** |
| 🔵 蓝色竖线 | 贴着左边导航栏的**右边缘** |

**如果全是 `√`，而且图上标记的位置都对，这一步就完成了，可以跳到第七步。**

> 💡 如果提示「荼蘼窗口被 XX 挡住了」或「窗口放不下要检查的 N 行」，说明这次没法可靠取色。把挡住荼蘼的窗口关掉（**上一次生成的检查图窗口就常常会挡住它**）、或把荼蘼窗口恢复成正常大小，再跑一次即可。工具这时会自动改用之前存下来的历史截图，结果同样可以参考。

如果位置不对，用记事本打开 `config.yaml`，找到 `monitor_settings:` → `row:`，按下面的对应关系改，改完再运行一次检查：

| 问题 | 改哪个 |
| --- | --- |
| 圆圈整体偏上或偏下 | `top_y`（第一行顶部的位置） |
| 越往下的行偏得越多 | `height`（每行的高度） |
| 圆圈整体偏左或偏右 | `content_left_x`（内容区左边缘） |

改一点点数字，再跑一次检查，重复几次就能调准。

**另外还有一步可选的**：从荼蘼界面上把"未启动"和"初始化"这两个状态文字**截图**下来，分别保存成：
- `res/tu_mi_status_not_started.png`
- `res/tu_mi_status_initializing.png`

不做也能跑，只是判断会稍微粗一点。

## 第七步：添加角色

1. **先把游戏开到登录界面**，账号下拉列表展开着。
2. 双击 **`启动菜单.bat`**，输入 `2` 回车，再选 `1`（新增角色）。

然后跟着提示走：

**① 输入角色名**：用英文小写字母，比如 `xiao_ming`。（只是个代号，随便起，不能和已有的重名）

**② 问你是不是渠道服账号**：官服账号直接回车（默认"否"）。

**③ 截取账号图片**：
   - 在黑窗口里按**回车**开始 8 秒倒计时（这时先别切窗口）
   - 倒计时期间把游戏切到前面，让**账号下拉列表展开着**
   - 倒计时结束，屏幕会被"拍照"定格
   - 在弹出的定格画面上，**按住鼠标左键拖动**，框住这个账号那一条，松开
   - 回到黑窗口，确认这张图可以就回车

**④ 截取角色图片**：同样的方法，框住角色列表里这个角色那一条（带等级和名字的，比如"170级 帅气花岗岩"）。

**⑤ 选脚本图片**：会列出已有的脚本图片，如果这个角色跑的方案和别人一样，直接输编号复用；不一样就输 `0`，然后用同样的「回车 → 倒计时期间展开荼蘼方案下拉列表 → 拖拽框选」方式截一张。

**⑥ 确认写入**：看一眼要写进去的内容，回车确认。

搞定！角色就加好了。

> **为什么是倒计时，而不是"调好界面再按个键"？**
> 因为下拉列表只要一点别的地方就会收起来，所以不能让你调好界面后再切回黑窗口按键。
> 那用热键呢？也不行——荼蘼和游戏客户端通常以管理员权限运行，Windows 出于安全考虑会**屏蔽**普通程序读取这类窗口获得焦点时的按键，表现就是"只有焦点在黑窗口时热键才管用"，而那恰恰是最没用的情况。
> 倒计时不需要读键盘、也不需要抢焦点，所以一定能用。要是没来得及调好界面，截完选 `n` 重拍即可。

> **中途关掉了怎么办？**
> 没关系，已经截好的图会自动保存。重新运行、输入同一个角色名，它会问你"要直接用已经截好的图吗"，选是就能接着上次的进度往下走。

## 第八步：先拿一个角色试跑

**第一次强烈建议只开一个角色试试**，确认整个流程能跑通，再把其他角色都打开。

1. 双击 `启动菜单.bat`，输入 `2` 回车，选 `2`（修改已有角色）。
2. 选中不想跑的角色，输入 `5` 切换成"停用"，然后输 `0` 保存。（对每个不想跑的角色都做一遍）
3. 手动**关掉所有一梦江湖窗口**。
4. 回到 `启动菜单.bat`，输入 `3` 开始挂机。
5. **然后就别碰电脑了**，看着它自己操作。

如果中间卡住了，看[常见问题](#常见问题)。

# 日常使用

## 每天怎么跑

1. **先手动关掉所有一梦江湖窗口**（重要，见下面的提示）。
2. 双击 **`启动菜单.bat`**。
3. 输入 `3` 回车。
4. **不要碰电脑**，等它跑完。

> ⚠️ **为什么要先关掉游戏窗口？**
> 程序启动时如果发现还有开着的一梦江湖窗口，它会先把这些窗口全部关掉，**然后等 30 分钟**才继续（避开游戏的重复登录限制）。所以提前关干净能省这 30 分钟。

跑的过程中，黑窗口里会一直刷日志，告诉你现在在干什么。这些日志也会存到 `app_年-月-日.log` 文件里，出问题时可以翻。

## 设置每天早上 5:05 自动运行

用 Windows 自带的「任务计划程序」，设置一次以后每天自动跑，不用管。

### 创建任务

1. 按 `Win + R`，输入 `taskschd.msc`，回车，打开**任务计划程序**。
2. 右边点 **"创建任务…"**（⚠️ 不要点"创建基本任务"，那个选项不全）。

**「常规」标签页：**

- 名称：随便填，比如 `一梦江湖每日挂机`
- 选中 **"只在用户登录时运行"** ⚠️ **这一项必须这样选**
- **不要**勾选"使用最高权限运行"（除非你用渠道服账号，见下面的说明）

> ⚠️ **为什么必须选"只在用户登录时运行"？**
> 另一个选项"不管用户是否登录都运行"会让任务在**没有桌面画面**的后台会话里跑。这个程序靠"看屏幕、点鼠标"工作，没有桌面就什么都干不了，会直接失败。

**「触发器」标签页** → 点"新建…"：

- 开始任务：选 **"按预定计划"**
- 设置：选 **"每天"**
- 开始时间：把时间改成 **`5:05:00`**
- 每隔 `1` 天发生一次
- 勾选 **"已启用"**
- 确定

**「操作」标签页** → 点"新建…"：

- 操作：选 **"启动程序"**
- 程序或脚本：点"浏览…"，选中项目文件夹里的 **`run_daily.bat`**
- **起始于（可选）**：填**项目文件夹的路径**（比如 `C:\Users\你的名字\clx_auto`）
  
  > 这一栏虽然写着"可选"，但建议填上。

**「条件」标签页：**

- ❌ **取消勾选** "只有在计算机使用交流电源时才启动此任务"（笔记本电脑必须取消，否则用电池时不会跑）
- ✅ 勾选 **"唤醒计算机运行此任务"**（这样睡眠状态下也能自动醒来跑）

**「设置」标签页：**

- ✅ 勾选 "如果过了计划开始时间，立即启动任务"（万一 5:05 时电脑关着，开机后会补跑）
- ❌ **取消勾选** "如果任务运行时间超过以下时间，停止任务"（挂机要跑好几个小时，别让它被掐断）

点"确定"保存。如果弹出让你输入密码，输入你 Windows 登录账户的密码即可。

### 还要做两件事，否则到点了也白跑

程序靠"看屏幕"工作，屏幕黑了、锁了它就瞎了。所以要关掉自动息屏和锁屏：

1. **关闭自动息屏**：设置 → 系统 → 电源和电池 → 屏幕和睡眠 → 把"接通电源时，在以下时间后关闭屏幕"和"使设备进入睡眠状态"都设成 **"从不"**。
2. **关闭锁屏**：设置 → 账户 → 登录选项 → "如果你离开，应在何时要求你重新登录" → 选 **"从不"**。

> 💡 另外记得**睡前手动关掉所有一梦江湖窗口**，不然程序 5:05 启动后会先关窗口再等 30 分钟。

### 验证是否设置成功

不用等到第二天早上。在任务计划程序里找到你刚建的任务，**右键 → 运行**，看程序是否正常启动。能正常跑起来就说明配置没问题，右键"结束"停掉即可。

任务的执行历史可以在下方"历史记录"标签页看；程序自己的日志在项目文件夹的 `app_年-月-日.log` 里。

> 用渠道服账号的话，因为需要管理员权限启动 idv-login，会弹 UAC 确认框。想让它无人值守跑的话，需要在「常规」标签页勾选"使用最高权限运行"。

## 调整同时挂机的角色数（并发数）

这是**换台电脑后最需要调的一个数字**，因为它直接受内存限制。

### 它是什么

`max_concurrent` 表示**同时开着几个游戏客户端在挂机**，默认 `6`。

配了 14 个角色、并发数设成 6，不是同时开 14 个游戏，而是：先开 6 个，其中任意一个跑完了，就自动补进下一个，直到 14 个全部跑完。剩下的角色在队列里排队等着。

### 为什么受内存限制

**每个游戏客户端都要单独占一份内存**，这是并发数的硬上限。

> 在作者的电脑上实测（32 GB 内存）：一个正常运行中的游戏客户端占用约 **4.8 GB**，刚启动还在加载的约 0.65 GB，荼蘼本体只占 139 MB。
>
> 这个数字会随游戏画质设置、角色所在场景、挂机脚本内容变化，**你的机器上可能不一样，一定要自己实测**。

开太多的后果不是"慢一点"，而是**游戏客户端直接崩溃**——表现为荼蘼那一行变粉红色，程序判定为异常退出、关掉窗口重试，白白浪费时间。

### 怎么算你的电脑能开几个

**方法一：先实测再算（推荐）**

1. 把并发数先改成 `2`，跑一次。
2. 等两个角色都进入游戏后，按 `Ctrl + Shift + Esc` 打开**任务管理器**，切到"详细信息"标签页。
3. 找到 `wyclx64.exe`（游戏客户端），看它的**内存**那一列占多少。
4. 按这个公式估算：

```
可开的并发数 =（你的总内存 - 4 GB 留给系统）÷ 单个客户端占用
```

例：16 GB 内存，实测单个客户端占 3 GB → `(16 - 4) ÷ 3 = 4` → 设成 **4**。

**方法二：直接按内存粗略参考**

| 电脑内存 | 建议并发数 |
| --- | --- |
| 8 GB | 1 ~ 2 |
| 16 GB | 3 ~ 4 |
| 32 GB | 6 ~ 8 |
| 64 GB | 10 |

> 这是按单客户端约 3~5 GB 估的，**务必用方法一实测校正**。

### 怎么改

用记事本打开 `config.yaml`，找到这一段，改 `max_concurrent` 后面的数字并保存：

```yaml
queue_settings:
  max_concurrent: 6          # 改成你算出来的数字
  pending_timeout_sec: 1800
  max_retries: 3
```

### 两个注意事项

**① 不能超过荼蘼的面板行数**

并发数不能大于 `monitor_settings` 里的 `max_visible_rows`（默认 10），否则荼蘼里没有空闲行可用，程序会报"荼蘼面板没有空闲行"并把角色判为失败。

**② 改小不会丢角色，只是变慢**

所有角色照样都会跑完，只是排队时间变长。总耗时大约是：

```
总时间 ≈ (角色总数 ÷ 并发数) × 单个角色的挂机时长
```

比如 12 个角色、单个跑 2 小时：并发 6 约 4 小时，并发 4 约 6 小时。**宁可少开也别开爆**——开爆了反复崩溃重试，反而更慢。

> 💡 拿不准就从小往大试：先设 3 跑一天，看任务管理器里内存用了多少、有没有角色异常退出，没问题再往上加。

# 常见问题

### 程序卡在那里不动，一直刷"未找到图片: res/xxx.png，继续寻找..."

程序在屏幕上找不到它要点的东西。按顺序检查：

1. **对应的界面是不是真的显示在屏幕上？**（比如它在找登录按钮，游戏是不是还没打开完）
2. **分辨率或缩放比例是不是改了？** 改了的话要重做[第五步](#第五步标定屏幕位置)。
3. **是不是游戏界面改版了？** 需要重新截取 `res/` 文件夹里对应的图片。

### 程序刚开始就不动了，等了很久

看黑窗口里有没有"已找到并关闭了 N 个一梦江湖的窗口"。有的话说明它检测到游戏还开着，正在**等 30 分钟**。以后运行前先手动关干净就行。

### 角色状态一直是"待运行"，30 分钟后失败重试

说明荼蘼那一行始终没变绿，也就是脚本没真正跑起来。可能是方案没选中、或者"开始"按钮没点上。

去[查看运行情况](#查看运行情况)页面，点进这个角色，看那个时间点的截图，就能看出荼蘼当时是什么状态。

### 角色频繁异常退出（页面上看到"失败"、荼蘼那行变粉红）

最常见的原因是**并发数设太高，内存不够导致游戏客户端崩溃**。

打开任务管理器看看跑满时内存占用是不是接近 100%。是的话，把 `config.yaml` 里的 `max_concurrent` 调小（比如从 6 改成 4），见[调整同时挂机的角色数](#调整同时挂机的角色数并发数)。

### 日志报"荼蘼面板没有空闲行"

`max_concurrent`（并发数）设得比 `max_visible_rows`（荼蘼面板行数，默认 10）还大了，荼蘼里没有足够的行来放这些任务。把并发数调小到不超过面板行数即可。

### 找不到角色，日志一直刷"向下滚动第 N 次继续查找"，但列表根本没动

两种原因：

1. **鼠标停在下拉框上，光标和悬停高亮盖住了列表里的那一条**，截图匹配就认不出来。现在点开下拉框后会等 `role_list_scroll.open_wait_sec`（默认 3 秒）让列表渲染出来，再按 `role_list_scroll.open_offset`（默认向右上 10px）把鼠标挪开，然后才开始识别；并且**每一轮滚动查找前都重新展开一次**下拉框（防止那一下点击被吞掉之后白滚一整轮）。失败时会在 `screenshots/<日期>/setup_fail_<角色>_<时分秒>.png` 留一张全屏截图，直接看图就知道当时卡在哪个界面。
2. **`role_list_scroll` 的 `point` 坐标没落在角色列表上**。鼠标滚轮只对**光标下面**的东西起作用，所以这个坐标必须在角色列表范围内。用 `helper.py` 重新量一个列表中间的坐标（见[第五步](#第五步标定屏幕位置)最后）。

> 注意下拉框的点击是「展开/收起」切换：万一列表本来就是开着的，重新点这一下会把它收起来，下一轮再点回来——所以 `max_rounds` 给了 4 轮富余，不要调回 3。

### 荼蘼每一行都读成一样的颜色

荼蘼面板标定不对，重做[第六步](#第六步检查荼蘼面板标定)。

### 渠道服角色登录失败

1. 检查 `config.yaml` 里 `idv_login_path` 路径对不对。
2. 运行时会弹**管理员权限确认框**，要点"是"。
3. 检查 `titles` 里 `idv_channel_account` 的窗口标题和你电脑上实际的是否一致。

### 日志文件用记事本打开是乱码

日志是 UTF-8 编码的。用记事本一般没问题；如果你用别的编辑器（比如 PyCharm、VSCode）打开乱码，把编辑器的编码切换成 **UTF-8** 即可。

### 想把配置改回去

每次修改配置前，程序都会自动备份成 `config.yaml.日期_时间.bak`。把想恢复的那个备份文件改名成 `config.yaml` 覆盖回去就行。

# 技术说明

> 下面是给会写代码的人看的，普通使用不需要了解。

## 工作原理

1. 打开荼蘼（未运行则自动启动），窗口移到屏幕 `(0, 0)`。
2. 关闭所有已打开的一梦江湖窗口（若有则额外 `sleep(1800)`）。
3. 读取 `config.yaml` 中 `enable: true` 的角色，按配置顺序入队。
4. **调度器（串行）**：有空闲并发槽位就取队首角色，执行「开游戏 → 选账号 → 登录 → 选角色 → 进游戏 → 荼蘼空闲行注册脚本 → 点开始」。这一整套依赖 PyAutoGUI 控制全局唯一的鼠标，必须串行；点完开始后角色交给荼蘼后台挂机，真正的并发体现在荼蘼里同时挂着多个角色。
5. **监控线程（并行）**：每 5 分钟截一次荼蘼窗口，逐行识别背景色和状态文字，更新状态、处理超时和异常退出。
6. 所有角色到达终态（运行完成 / 失败）后退出。

## 队列状态机

```
排队中 ──(有空闲槽位)──> 待运行 ──(行变绿 且 不是"初始化")──> 运行中 ──(行变白)──> 运行完成
            ▲                  │                                    │
            │                  │(超过30分钟)                        │(行变粉红=异常退出)
            └──── 重试<=3次 ────┴────────────────────────────────────┘
                                   │(重试>3次)
                                   ▼
                                  失败
```

- **待运行 → 运行中**：需要行背景变绿**且**荼蘼原始状态文字不是「初始化」，两个信号同时满足才切换。
- **运行中 → 运行完成**：只看行颜色变白。单次运行至少 1 小时，不会和初始的「未启动」混淆。
- **异常退出**：行背景变粉红 `(255,192,203)`，不等超时直接判失败重试，同时自动点掉荼蘼弹出的错误对话框（标题匹配 `.*错误.*插件版本.*`）。
- 失败重试会按 pid 精确关闭该角色的游戏窗口，不会误关别的角色。
- **setup 阶段失败**（登录/选角色/在荼蘼里选方案时图片一直识别不到）也会先清理再重试：按「本次 setup 前后的『一梦江湖』窗口差集」关掉这一次新开的窗口（跳过 pid 属于已在运行的客户端的窗口，不误杀并发中的角色），窗口还没建出来就失败时按启动器进程 pid 兜底，渠道服的 idv-login 残留进程也一并关掉。否则每重试一次就多留一个窗口，很快堆满屏幕。
- 每次「登录完成 → 操作荼蘼」之前，以及扫描空闲行之前，都会先把荼蘼窗口拉回 `(0,0)` 并强制置前：刚进游戏时前台是游戏客户端，会把荼蘼整个盖住，此时按坐标点刷新/方案下拉框会点到游戏窗口上。
- **荼蘼界面操作是原子的**：「置前 → 刷新 → 展开方案下拉列表 → 认出方案 → 点开始」这一整段在一把全局互斥锁里执行，监控线程的「点掉错误弹窗 + 截图」和调度器的「扫描空闲行」都要排队等它做完，不会插进来把展开着的下拉列表收掉。监控线程等锁最多 `monitor_settings.ui_lock_timeout_sec`（默认 180 秒），超时就跳过本轮、下一轮再看，不会被卡死。选方案这一段单次失败还会**就地重做**（次数 `retries.tu_mi_script_select`，默认 3），实在不行才抛给调度器让角色重新登录。
- 已确认的参考色：运行中 `(144,238,144)`，异常退出 `(255,192,203)`。

## 配置项

### `roles`

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 角色名，蛇形命名，也是图片文件名前缀 |
| `account_image` | 官服必填 | 账号下拉列表中该账号的截图 |
| `login_role_image` | 是 | 角色列表中该角色的截图 |
| `script_image` | 是 | 荼蘼方案列表中该方案的截图，可多角色共用 |
| `channel_account` | 否 | `true` 表示渠道服账号，走 idv-login；默认 `false` |
| `enable` | 否 | `false` 则不参与运行；默认 `true` |

队列入队顺序 = 配置顺序。

### `global_settings`

| 字段 | 说明 |
| --- | --- |
| `points` | 固定点击坐标（绝对屏幕像素）：`select_role`、`tu_mi_daily_menu`、`script_choose_base` / `script_run_base`（荼蘼第 1 行，其余行按 `monitor_settings.row.height` 推算）、`script_dropdown_offset_y` |
| `regions` | 图像搜索范围，格式为 `left / top / width / height`（**不是四个角坐标**）：`account_list` 账号下拉列表、`script_list` 方案下拉列表（`top` 由程序按行号算，不用配） |
| `images` | 通用界面元素的图像模板路径，共 12 张：`init_known` / `other_account` / `logo` / `an_login` / `login_enter_game` / `role_enter_game` / `account_selection` / `dream_server` / `dream_checkbox` / `tu_mi_logo` / `tu_mi_main` / `tu_mi_refresh`。其中 `tu_mi_logo`（托盘图标）只在**兜底路径**用：启动时优先按 pid + 窗口标题直接把荼蘼主窗口唤出来（最小化到托盘的窗口是被 `SW_HIDE` 藏起来的，句柄一直在，`SW_SHOW` 就能请回来），找不到窗口才退回去认托盘图标 |
| `image_match` | `confidence` 匹配相似度阈值、`retry_interval_sec` 找图失败后的重试间隔、`default_max_retries` 默认重试上限 |
| `retries` | 各步骤单独的找图重试次数上限（`other_account` / `logo` / `an_login` / `account_selection` / `login_enter_game` / `dream_checkbox` / `role_enter_game` / `tu_mi_refresh`） |
| `account_list_scroll` | 账号列表用方向键逐条翻找的参数：`first_press_count` 首轮按键数、`next_press_min` / `next_press_max` 之后每轮的随机步长、`max_attempts` 最大轮数、`channel_pagedown_count` 渠道服账号先整页翻几次 |
| `role_list_scroll` | 角色列表滚轮翻页：`point` 滚动时鼠标位置（必须落在列表内，滚轮只对光标下的控件生效）、`clicks` 每次滚动格数（负数向下，建议略小于一屏以保证重叠）、`max_scrolls` 单轮最大滚动次数、`max_rounds` 重新展开+回顶重试的轮数、`open_wait_sec` 点开下拉框后等列表渲染的秒数、`open_offset` 展开后把鼠标从下拉框上挪开的偏移（默认向右上 10px，避免光标盖住列表项） |
| `delays` | 11 项等待时长：`global`（即 `pyautogui.PAUSE`）、`software_init`、`after_game_launch`、`relogin_wait`（关掉残留游戏窗口后的等待，默认 1800）等 |
| `timeouts` | 9 项超时：`find_window` / `bring_to_front` / `wait_process` / `new_game_window` / `kill_process` / `poll_interval` 等 |
| `process_keywords` | 按可执行文件路径定位进程的关键字：`tu_mi` / `idv_login` |
| `titles` | 窗口标题与按钮文字：`tu_mi` / `clx` / `idv_channel_account` / `timezone_warning`(正则) / `timezone_warning_button` / `tu_mi_error_popup`(正则) / `tu_mi_error_popup_button`。游戏或荼蘼改版、换语言版本时改这里 |
| `software_path` / `script_path` / `idv_login_path` | 一梦江湖启动器、荼蘼、idv-login 的可执行文件路径 |

## 命令行用法

所有功能也可以直接跑脚本（需在项目根目录下执行，程序用相对路径读 `config.yaml`、写 `state/` 和 `screenshots/`）：

```bash
python daily_cleanup.py        # 开始挂机
python manage/roles.py         # 角色管理（新增/修改）
python manage/calibrate.py     # 荼蘼面板标定检查，生成标注图
python manage/server.py        # 本地状态查看页，--port 换端口，--no-browser 不自动开浏览器
python helper.py               # 实时显示鼠标坐标，用于标定点位
```

状态查看页只监听 `127.0.0.1:8765`，仅本机可访问。

## 已知限制

- **强依赖屏幕坐标和图像识别**：换机器、换分辨率、换 DPI 缩放、界面改版都要重新标定，详见[从别人那里拿到这个项目](#️-从别人那里拿到这个项目先看这里)。
- **图像匹配不做多尺度搜索**：`pyautogui.locateOnScreen(confidence=0.8)` 底层是单尺度 `matchTemplate`，模板与实际渲染尺寸不一致就必然失败，不会自动缩放去凑。这是模板不能跨分辨率复用的根本原因。
- **管理页面只读**：不能从页面手动重跑某个角色。
- **单显示器假设**：多显示器环境坐标可能错乱，未做适配。
- **修改角色会重写该角色的配置块**：块内自定义注释会被标准注释覆盖，其他角色和段落注释不受影响。
- `state/`、`screenshots/`、日志、`config.yaml.*.bak`、`标定检查图.png` 均为运行时数据，已加入 `.gitignore`。
- 不要在 `config.yaml` 或代码里写入账号密码等敏感信息。
