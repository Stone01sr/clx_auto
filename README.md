# clx_auto

一键运行「一梦江湖」荼蘼挂机脚本：自动完成开号登录、选角色、进游戏、在荼蘼里注册预设脚本并启动，并按队列方式管理并发数量，全程监控荼蘼运行状态，支持本地页面查看当天及历史运行情况。

## 功能概览

- **批量登录**：按 `config.yaml` 中配置的角色顺序，自动完成账号选择/登录、角色选择、进入游戏（渠道服账号通过 `idv-login` 辅助登录）。
- **队列调度**：同时运行角色数可配置（默认6），超出并发上限的角色进入等待队列，有空闲槽位时自动补位。
- **状态监控**：定时截图荼蘼窗口，按行识别背景色（绿=运行中、粉/红=游戏客户端异常退出）和状态文字，驱动 排队中→待运行→运行中→运行完成 的状态流转。
- **异常处理**：待运行超时（默认30分钟）或检测到行变红（异常退出）自动重试，最多重试3次，超过后标记为失败，需人工介入；游戏异常退出时荼蘼弹出的错误对话框会被自动检测并点掉，避免卡住后续操作。
- **本地查看页**：`manage/server.py` 起一个本地HTTP页面，按日期查看每个角色当天的状态、荼蘼原始状态、重试次数，以及状态变迁的截图记录。

## 环境依赖

- Python 3.11
- 依赖包见 `requirements.txt`：

```bash
pip install -r requirements.txt
```

## 配置

所有可调参数集中在 `config.yaml`，禁止在代码里硬编码：

- `roles`：要挂机的角色列表（账号图片、登录角色图片、脚本图片、是否启用）。
- `global_settings`：软件路径、固定点位坐标、图像识别模板路径、延迟时间等。
- `queue_settings`：并发数、待运行超时时间、最大重试次数。
- `monitor_settings`：截图轮询间隔、荼蘼面板行位置/高度、状态文字模板。
- `storage_settings`：状态JSON与截图的存放目录、数据保留天数。

> 荼蘼面板的行坐标、取色点、图像模板均按当前显示分辨率标定，换机器/换分辨率后需要重新截图校准。

## 运行

```bash
python daily_cleanup.py
```

或直接双击 / 用计划任务运行 `run_daily.bat`（会先激活对应的 conda 环境）。

运行日志会同时输出到控制台和当天的 `app_YYYY-MM-DD.log`（UTF-8 编码）。

## 查看运行状态

```bash
python manage/server.py
```

默认启动后自动打开浏览器访问 `http://127.0.0.1:8765/`，可切换日期查看当天/历史队列运行情况；仅监听本机地址，不支持局域网访问。`--port` 换端口，`--no-browser` 禁止自动打开浏览器。

## 项目结构

```
clx_auto/
├── daily_cleanup.py      # 主入口：登录/选角色/注册脚本的自动化流程 + 队列调度器与监控线程的启动/收尾
├── config.yaml            # 唯一配置来源：角色列表、点位、队列/监控/存储参数
├── requirements.txt       # Python依赖
├── run_daily.bat           # 定时任务/手动运行入口
├── helper.py                # 开发辅助：实时显示鼠标坐标，用于标定点位和截图区域
├── snatch_veggies.py        # beta功能，仅作存档，未接入主流程
├── res/                      # 图像识别模板（账号/角色/按钮等截图）
├── veggies/                  # beta功能相关模板图片，仅作存档
├── tu_mi_queue/               # 队列子系统
│   ├── models.py                # 状态枚举（TaskStatus）、RoleTask/HistoryEntry、QueueState队列容器
│   ├── scheduler.py             # 串行setup worker：登录/选角色/在荼蘼注册脚本并点击开始
│   ├── monitor.py               # 定时截图荼蘼窗口，识别行颜色/状态文字，驱动状态机；检测并关闭异常退出错误弹窗
│   └── state_store.py           # 每日状态JSON落盘、截图留存、过期数据清理
├── manage/
│   └── server.py                 # 本地队列状态查看页（http://127.0.0.1:8765）
├── state/                       # 运行时数据：每日队列状态JSON（不入库，见.gitignore）
├── screenshots/                  # 运行时数据：每轮监控截图，按日期分目录（不入库）
└── app_YYYY-MM-DD.log             # 每日运行日志，UTF-8编码（不入库）
```

## 注意事项

- 荼蘼软件全程只保持一个实例，窗口大小/位置固定；行坐标、取色点是按标定后的分辨率写死的，界面变化后需要重新标定。
- `state/`、`screenshots/`、日志文件均为运行时数据，已加入 `.gitignore`，按 `storage_settings.retention_days`（默认30天）自动清理。
- 不要在 `config.yaml` 或代码里写入账号密码等敏感信息。
